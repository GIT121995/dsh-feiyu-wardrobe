# 大肥鱼衣橱 · 服装设计圣经

> **内容基调（2026-11-02 用户确认，优先级最高）：本项目核心卖点是「养女儿」——
> 衣服要保守（长袖/有领/及膝以上长度，不出现露肩露背的礼服、蕾丝抹胸等），
> 互动台词要温和克制（陪伴/吃饭/日常方向，不含任何暗示或身体评价）。
> v0.8.0 起套装只保留「经典女仆装」，其余礼服类已移除。**

> 换装间的衣服不是「随便好看就行」——每套衣服都要能回答一个问题：**它反映了大肥鱼的什么？**
> 这份文档是设计基准：人设 → 设计语言 → 系列规划 → 单套 brief。

## 一、角色底层人设（三层）

| 层 | 身份 | 来源 | 关键词 |
|---|---|---|---|
| 打工鱼 | AI 助手 / 服务者 | DeepSeek 鲸鱼 logo 的社区二创 + 女仆装 | 服务、被使用、认真干活、烧 token |
| 干饭鱼 | 「吃白饭的大肥鱼」 | 社区梗：DeepSeek 便宜/免费，被戏称白嫖白吃；本项目把 token 花销 = 鱼粮 | 白饭、鱼粮、记账、省钱、馋 |
| 宅鱼 | 开发者 / 开源社区的日常 | 程序员刻板印象（卫衣、工牌、摸鱼） | 宽松、躺平、藏起来、下班 |

**一句话人设**：

> 一只明明在给人类拼命打工（烧 token），却总被调侃「吃白饭」，于是自己偷偷记账省鱼粮、嘴硬心软的鲸鱼女仆。

**反差萌是核心**：上班是女仆（服务者），下班是卫衣宅鱼；嘴上说「我不是吃白饭的」，身体很诚实。

## 二、为什么是「女仆装」和「套头衫」

- **女仆装 = 上班的工服**：AI 助手本质是服务者；围裙天然连着厨房与「白饭」；荷叶边/蝴蝶结是二次元萌系契约，让「服务」这件事变得可爱、无攻击性。
- **套头衫/卫衣 = 下班的私服**：宽松、连帽、不修边幅，是程序员/宅/开源社区的制服；连帽还带一点「把自己藏起来」的社恐感；配一张工牌（如参考图里的 Claude 工牌），就是「AI 打工人」的现代版工服。
- **两者的对比就是人设**：努力打工 ↔ 想摸鱼偷懒；被使唤 ↔ 吃白饭；高冷女仆 ↔ 馋嘴宅鱼。

## 三、设计语言

### 3.1 配色公式（每套衣服按 60/30/10 来）

| 颜色 | 用途 | 参考色 |
|---|---|---|
| 深海蓝 | 本体、主服装（职业感） | `#1e3a8a` → `#60a5fa` 渐变 |
| 米饭白 | 围裙、内搭、卫衣（白饭 / 干净感） | `#ffffff` / `#f8fafc` |
| 鱼粮金 / 橙 | 点缀（工牌、蝴蝶结、发夹、鞋子细节） | `#f59e0b` / `#fbbf24` |
| 一点点粉 / 红 | 情绪色（害羞、节日限定） | `#f9a8d4` / `#ef4444` |

> 参考图（白卫衣 + 橙百褶裙 + 蓝发 + 橙花发夹 + 工牌）就是这套公式的完美实例——可以直接当「工牌卫衣」的设计参考。

### 3.2 标志性元素（每套至少 2 个，缺了就认不出是大肥鱼）

- **必须露**：鲸鱼尾巴（从裙摆侧后方伸出）、鲸鱼耳鳍、头顶呆毛
- 鲸鱼图案（围裙、胸口、袜子、工牌）
- 白饭 / 饭碗 / 米粒（干饭鱼）
- 鱼粮 / 金币 / 账本 / 小票（经济系统）
- 工牌 + 挂绳（打工人）
- 荷叶边 / 蝴蝶结 / 围裙系带（女仆契约）
- 星星 / 橙花发夹（参考图元素，可做成系列符号）

### 3.3 剪裁原则

- **Q版**：上身短、下摆大；尾巴从侧后方露出；长袖子可以盖过手（萌 + 藏手）
- **少女版**：约六头身、收腰/ A 字；尾巴和耳鳍仍要露出来
- **禁止**：公主大蓬蓬裙（她不是公主）、机甲战斗装（不是战斗系）、纯性感路线（社区萌系）

### 3.4 颜色禁忌

- 大面积黑金 → 会变成哥特，偏离「打工人」；只适合节日限定
- 大面积荧光赛博 → 偏离日常；只适合主题限定
- 主系列必须保持「深海蓝 + 白 + 橙点缀」的可识别性

## 四、服装系列规划

四条线，每条 3–4 套：

1. **打工线（服务者身份）**
   - 经典女仆装（✅ 已上线）
   - 食堂围裙女仆（白饭食堂 → 围裙上是饭碗 + 鲸鱼）
   - 甜品店女仆（奶油/草莓，已有草莓蛋糕裙可归入）
   - 公司工牌卫衣（白卫衣 + 橙裙 + 工牌 + 橙花发夹）
   - 便利店店员（马甲 + 收银小票梗）
2. **干饭线（白饭梗）**
   - 白饭食堂装（饭碗头饰、围裙、饭勺）
   - 鱼粮收藏家（金币/鱼粮挂件、钱包）
   - 饭团睡衣（米粒印花）
   - 中秋限定（月饼 / 月亮）
3. **宅家线（开发者日常）**
   - 长款睡袋卫衣（oversized、帽子带鲸鱼耳鳍）
   - 水手服 / 校园日常
   - 雨衣（下雨天也不想上班）
4. **节日梗**
   - 新年红包、圣诞毛衣、万圣南瓜鲸

配饰小物（后续可做叠加层）：工牌挂绳、橙花发夹、饭碗手持、鱼粮钱包、账本。

## 五、每套衣服的「设定 + 台词」原则

每套衣服在 manifest 里除了 `desc`，再配一句人设台词（后续 UI 在信息条展示）：

- 打工类：「今天也努力打工了…才怪。」「主人，鱼粮结一下？」
- 干饭类：「我不是吃白饭的！」「就一口，真的就一口。」
- 宅家类：「今天可以不出门吗？」「卫衣口袋里有薯片。」
- 节日类：「这是节日限定，不是乱花钱。」

## 六、落地顺序

1. **本轮概念验证**（4 套，先出 Q 版）：工牌卫衣、食堂围裙女仆、睡袋卫衣、水手服日常
2. 用户挑选 → 每套 × Q版/少女版 正式出图 → 更新 manifest + 台词 → 发 **v0.7.0**
3. 后续按系列补：便利店、白饭食堂、鱼粮收藏家、节日限定…
