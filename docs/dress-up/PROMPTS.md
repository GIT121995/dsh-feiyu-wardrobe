## 裙子图层生成配方（AI 只画裙子）

```
Q版动漫风格，只有一条华丽的{主题}大裙子，裙子正面展示，
没有人物、没有身体、没有头、没有腿，蓬松多层裙摆，
深色描边，平涂上色，白色背景，居中，干净简洁，无文字
```

主题示例：

| id | 主题描述 |
|---|---|
| starry | 深蓝星空渐变、星光点缀、缎带蝴蝶结的 |
| strawberry | 粉白奶油渐变、草莓装饰、层层褶皱的 |

| forest | 嫩绿渐变、花瓣层叠、藤蔓小花的森林仙子风 |
| cyber | 半透明材质、青紫色霓虹光边、几何光纹的赛博风 |

## 合成新裙子

```sh
# 1) AI 生成裙子图（白底）→ /tmp/skirt.png
# 2) 合成到经典底座（自动去白底、按 Q 版比例对齐腰部）
python3 tools/compose_dress.py sprites/正面_306.png /tmp/skirt.png /tmp/out.png
# 3) 转 WebP 放进 dresses/，更新 manifest.json 的 file 即可
```


目标：同一只角色、同一姿势、不同大裙子 → 前端换装 demo 的素材。

## 参数建议

- 比例 **2:3 竖图**（1024×1536 或更高），全身必须完整入画
- 背景**纯白**（便于去底），不要文字/水印
- 同一个 seed 或同一张参考图 + 只改裙子描述，能显著提高角色一致性
- 每套出 2–4 张候选，挑姿势/脸最接近的

## 加进 demo

```sh
# 1) 原图放这里（不入库）
mkdir -p docs/dress-up/raw
# 2) 去白底 + 统一高度 1200
python3 tools/prepare_dress.py docs/dress-up/raw/starry.png docs/dress-up/dresses/starry.png
# 3) 按 docs/dress-up/manifest.json 的 id 更新文件名即可，刷新页面生效
```
