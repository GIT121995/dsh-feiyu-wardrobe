# 2.5D runtime 接入说明（v2.0.0 · 2.5D-only）

> 自 v2.0.0 起换装间**只有 2.5D 渲染这一条可见路径**：DOM 分层纸娃娃（v6/v7 的 `drawOrder`/`layers`/B1-lite 脸部补丁）、
> 双模式开关（`config.dressUp.render` / `?render=`）、`render-config.json` 端点、静态兜底图均已删除（用户拍板的高风险方案 B）。
> v1.0.0 的双模式实现见 git 历史（`feat/2.5d-runtime` 分支 / v1.0.0 tag）。

## 1. 行为与开关

| 场景 | 行为 |
|---|---|
| 浏览器支持 WebGL2 | 进入换装间即启动 2.5D runtime（按需加载当前身形 rig + 图集）；无可切换的「DOM 模式」 |
| 浏览器不支持 WebGL2 / context lost（永久失败的 context） | **只显示纯文本提示 + 重试按钮**（「当前浏览器/设备不支持 WebGL2，换装间需要 WebGL2；请升级浏览器或开启硬件加速（GPU 渲染）」）；**不做静态图/人物兜底**，不保留第二套渲染 |
| `prefers-reduced-motion: reduce` | 关闭随机眨眼/笑眼等自动动画与互动动作曲线（画面仍静态渲染；互动台词/HUD 正常） |
| 宿主互动开关 | `config.dressUp.interaction.enabled`（默认 `true`）→ `client-config.json` 下发 interaction 端点；关闭/静态托管 → 页面 local-only（只播台词/动作，不扣鱼粮） |

页面 boot 不再读任何渲染配置；`client-config.json` 只含 `{version:2, interaction:{enabled,stateUrl,actionUrl}}`。

## 2. 资产与加载

```
docs/dress-up/art/2d5/<shape>/
├── rig.json        # 紧凑 rig（chibi ≈1.72MB raw / ≈293KB gzip；girl ≈1.60MB / ≈268KB）
├── atlas.webp      # 单张 lossless 图集（chibi 2028×2216 / girl 1991×2192）
└── build-report.json
```

- **按需加载**：页面 boot `import('./runtime-2d5.js?v=14')` → `fetch(art/2d5/<shape>/rig.json?v=13)` + `atlas.webp?v=13`；
  只加载当前身形，切身形时加载目标 → 激活 → 释放旧 GL 资源（参数/物理/时间保留）。
- **资产版本**：rig/atlas 的 fetch URL 带 `?v=13`（由 app.js 传 `assetVersion` 给 runtime）；页面模块版本 v14。
  资产内容不变时不必改资产版本；替换资产（M4 production / 后续）时同步提升资产版本。
- **构建**：`python3 tools/build_2d5.py --rig <rig> --texdir <tex> --out docs/dress-up/art/2d5 --shape <chibi|girl>`
  （best-fit 图集打包 + UV 重映射 + 定点化 + `pixelEqual`/UV/引用完整性校验；失败退出码 1，不要手改产物）。
- 首屏 payload（headless，gzip）：runtime 2 个 JS ≈24KB + rig ≈293KB + atlas ≈1.27MB ≈ **1.5MB**（仅当前身形）。
- **DIY 参考掩膜**：`art/diy/masks/chibi/{body,hair,arms}.webp` 是 DIY 本地成层算法（fill-under-hair/拆袖）的不可见输入，
  不是渲染资产/人物图层；只有 `docs/dress-up/diy-*.js` 引用。

## 3. runtime API（`docs/dress-up/runtime-2d5.js`）

```js
import { createRuntime2D5 } from './runtime-2d5.js?v=14';
const rt = await createRuntime2D5({ canvas, assetRoot: 'art/2d5/', assetVersion: '13', quality: 'auto', device });
await rt.setShape('chibi');          // 按需加载 + 激活（切身形释放旧资源，参数/物理/时间保留）
rt.setLook({ outfit, top, bottom }); // 套装优先；否则上衣+下装动态组合（缺件回退 + warnings）
rt.setParams({ headY: 6, breath: 0.8 }); // 参数总线（见 §4）
rt.setHeadFollow(nx, ny);            // 指针跟随（-1..1；null=回正）
rt.triggerBlink(); rt.triggerSmile(); rt.triggerTalk(1.2); rt.setTalking(true); rt.tap();
rt.setQuality('low'|'medium'|'high'|'auto'); rt.setDPR(1.5); rt.setPhysicsHz(30);
rt.setMaskPass(false); rt.setMipmaps(true); rt.setStatic(true); rt.setAuto(false);
rt.start(); rt.stop(); rt.setPaused(hidden); rt.freeze(true); // 冻结后手动 step/advance 确定性截图
rt.step(1/60); rt.advance(60, 1/60); rt.renderFrame();
rt.renderToCanvas(ctx2d, x, y, w, h);   // 立绘卡合成（当前帧 → 2D canvas）
rt.toDataURL({ width: 184, height: 328 }); // 悬浮鲸鱼小图（透明底 dataURL）
rt.getMemory(); rt.getQuality(); rt.getState(); rt.getAssetInfo(); rt.getTickInfo();
rt.destroy();
```

纯逻辑（画质档/参数钳制/换装组合/可见 drawable/face 状态机/固定步长）在 `runtime-2d5-core.js`，node 单测覆盖。

## 4. 参数总线（M5 互动接口）

`setParams(partial)` 接受键（越界钳制，未知键忽略）：`headX` / `headY` / `headZ`（±25°）、`breath`（0–1）、
`eyeOpen` / `eyeSmile`（0–1）、`mouthOpen`（0–1）、`hairSway` / `skirtSway`（0–1）。
另有临时通道：`setTalking(true)` 口型循环、`triggerBlink/Smile/Talk`、`tap()`（轻点头+笑眼+眨眼）。
参数曲线/动作状态机在 `interaction-model.js`，由 app.js 的 `playAction()` 驱动。

## 5. DIY 静态贴片（v2）

- DIY 本地衣柜逻辑不变（IndexedDB 记录 → 注入 `manifest.items`，`item.layers[shape][slot] = blobURL`）。
- 选中 DIY 条目时：runtime `freeze(true)`（暂停物理/动画）+ canvas 2D overlay 按槽位顺序
  （`bottom → topBody → sleeve`，见 `wardrobe-core.diyLayerUrls`）叠加全画布 675×1200 位图；
  UI 提示「DIY 造型为静态，不支持骨骼动画」；**不允许退回 DOM**。
- 立绘卡/悬浮鲸鱼会把静态帧 + DIY 贴片一起合成；切回非 DIY 条目恢复动态。
- DIY 记录 `shape=chibi`：girl 身形下选中 DIY 条目会提示「DIY 单品只做了 Q 版」并用普通 2.5D 造型。

## 6. 页面接线（`docs/dress-up/app.js`）

- `bootRuntime()`：2.5D 是唯一路径；失败 → `showRuntimeUnavailable()` 只显示文本提示（可重试）。
- `applyState()` → `sync2d5()`（setShape/setLook/DiyStatic/renderFrame）+ 背景/特效/衣柜/立绘卡元信息刷新。
- `say()` → runtime 口型；`pointermove` → head follow；角色点击 → 头部摸头/身体 tap；`saveCard()` → `renderToCanvas` 合成；
  `composePetImage()` → runtime 帧（+ DIY 贴片）→ `toDataURL` 写悬浮鲸鱼小图。
- E2E/调试入口：`window.__feiyu2d5`（ready/runtime/failure/unavailable/retry/getState/getMemory/diyMode/
  diyOverlayVisible/simulateDiy/clearDiy/freeze/setAuto/advance/step/resources）。

## 6.5 cutout 槽位与多图集（v2.2 目标，M3 已支持）

B 方案（Live2D/Spine 式 cutout 素体重制）新增 drawOrder 槽位与「每身形 1–2 张图集」；M3 已把 runtime/core 改好，
production 资产由 M4 合入后启用（本分支不改 `art/2d5`）。

| 槽位 | z | 语义 |
|---|---:|---|
| `legs` | 9 | 腿/脚 cutout 部件（先绑 hips，裙子后面） |
| `body` | 10 | 躯干（原 body 槽位语义不变） |
| `armUpper` / `armFore` / `hand` | 45 / 48 / 65 | 上臂 / 前臂 / 手（服装 sleeve 之下/上按 z 排） |
| `collar` | 56 | 领/胸饰/围裙等独立层（服装槽位，随 outfit） |
| `sleeveUpper` / `sleeveFore` | 60 / 62 | cutout 袖子分段（手 z65 在袖口外） |

- `BODY_DRAW_SLOTS`：`hairBack/strands/body/legs/arms/armUpper/armFore/hand/hair/hairFront/collar`（来自 `rig.slots` 常驻层）。
- `OUTFIT_SLOTS`：旧 `topUnder/bottom/topBody/sleeve` + 新 `sleeveUpper/sleeveFore/collar`；outfit 可同时给多槽位。
- **多图集**：rig 用 `atlases: [{id,file,width,height}, …]`（≤2 张）；每个 drawable 用 `atlas` 指定 id/下标/文件名，
  缺省第一张。旧 rig 的 `atlas: {file,width,height}` 单图集继续加载；旧 `getState().look.slots` 的 4 个键语义不变
  （cutout 新槽位仅在非空时追加，旧路径字节级不变）。加载请求 +1/张图集（首屏 ≤2 张）。
- `resolveLook` 输出 slots 为 7 键全集；runtime `getState().look.slots` 对旧 rig 仍只返回 4 键。
- DIY 增量 pack 兼容：`topBody/bottom/sleeve/topUnder` 语义不变；新槽位 `sleeveUpper/sleeveFore/collar` 可直接写入 pack，
  旧别名 `arms/arm/sleeves → sleeve` 自动映射；`addOutfitPack/removeOutfitPack` 与多图集 scene 兼容（DIY 纹理独立）。
- 校验：`normalizeAtlases`（≤2、重复 id/缺 file 报错）、`resolveDrawableAtlas`；core 单测覆盖。

## 7. 已知限制（v2 初版）

1. **无 WebGL2 用户失去换装间**（用户已接受）：只有文字提示，无静态人物/兜底图。
2. **DIY 为静态贴片**：贴片叠在 2.5D 静态帧最上层，可能盖住个别手臂/发丝细节；无骨骼动画/物理。
3. **真机性能未测**：所有 FPS/CPU/内存为服务器侧 headless（SwANGLE 无 GPU）数据，不可代表真机；不做 60fps 承诺。
4. 背景/特效仍在 DOM/CSS 层（透明 canvas 只画角色）；换背景不触发 canvas 重绘。
5. 历史文档（`PLAN-2.5D-RIG.md`、`LAYER-MODEL.md`、`DIY-UPLOAD.md`）保留作历史参考，其中 DOM 相关章节已退役。
