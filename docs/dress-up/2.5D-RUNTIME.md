# 2.5D runtime 产品化接入说明（M3）

> 本文面向 M5（互动/动作库）与 M6（集成/发版）：说明 2.5D canvas runtime 如何接入换装页、开关怎么用、参数总线/API 在哪、失败如何回退。
> 背景：POC 在 `.scratch/m2-full/poc/`（未进产品）；M3 把它整理为产品 ES 模块并接入换装页，**默认关闭**，DOM 分层纸娃娃仍是默认与 fallback。
> 资产规范见 `.scratch/m3/ASSET-SPEC-2D5.md`；M3 报告见 `.scratch/m3/REPORT.md`。

## 1. 开关（三层优先级：URL > 用户选择 > 宿主配置 > 默认 dom）

| 层 | 用法 | 说明 |
|---|---|---|
| 宿主配置 | `config.dressUp.render = 'dom' \| '2d5' \| 'auto'` | 默认 `'dom'`；`auto` = WebGL2 可用且非 reduced-motion/低内存时开 2.5D。由 `lib/config.js` 校验，经 `/feiyu/dress-up/render-config.json` 下发给页面 |
| URL | `?render=2d5` / `?render=dom` / `?render=auto` | 灰度/回滚开关；优先级最高 |
| 用户选择 | 页面右上「🧊 2.5D / 🎨 DOM」按钮 | 点击切换并写 `localStorage['feiyu:render']`，下次访问优先于宿主配置 |
| 默认 | 以上都无 → `dom` | 默认不 import runtime、不请求任何 2.5D 资产 |

## 2. 资产与加载

```
docs/dress-up/art/2d5/<shape>/
├── rig.json        # 紧凑 rig（MVP：每身形 1.5MB raw / ~270KB gzip）
├── atlas.webp      # 单张 lossless 图集（chibi 2041×2099 / girl 1991×2188）
└── build-report.json
```

- **按需加载**：只有进入 2.5D 才 `import('./runtime-2d5.js')` → `fetch(art/2d5/<shape>/rig.json)` + `atlas.webp`；单身形单套，切身形时加载目标→激活→释放旧 GL 资源。
- **构建**：`python3 tools/build_2d5.py --rig <POC rig> --texdir <纹理目录> --out docs/dress-up/art/2d5 --shape <chibi|girl>`（图集打包 + UV 重映射 + 定点化 + 回读逐像素校验）。
- 首屏 payload（headless 实测，gzip）：runtime 2 个 JS ~76KB + rig 270KB + atlas 1.18MB ≈ **1.44MB**（仅当前身形）。

## 3. runtime API（`docs/dress-up/runtime-2d5.js`）

```js
import { createRuntime2D5 } from './runtime-2d5.js?v=12';
const rt = await createRuntime2D5({ canvas, assetRoot: 'art/2d5/', quality: 'auto', device });
await rt.setShape('chibi');          // 按需加载 + 激活（切身形释放旧资源，参数/物理/时间保留）
rt.setLook({ outfit, top, bottom }); // 套装优先；否则上衣+下装动态组合（缺件回退 + warnings）
rt.setParams({ headY: 6, breath: 0.8 }); // 参数总线（见 §4）
rt.setHeadFollow(nx, ny);            // 指针跟随（-1..1；null=回正）
rt.triggerBlink(); rt.triggerSmile(); rt.triggerTalk(1.2); rt.setTalking(true); rt.tap();
rt.setQuality('low'|'medium'|'high'|'auto'); rt.setDPR(1.5); rt.setPhysicsHz(30);
rt.setMaskPass(false); rt.setMipmaps(true); rt.setStatic(true); rt.setAuto(false);
rt.start(); rt.stop(); rt.setPaused(hidden); rt.freeze(true); // 冻结后手动 step/advance 确定性截图
rt.step(1/60); rt.advance(60, 1/60); rt.renderFrame();
rt.renderToCanvas(ctx2d, x, y, w, h);   // 立绘卡合成（当前帧 → 2D canvas）
rt.toDataURL({ width: 184, height: 328 }); // 悬浮鲸鱼小图（透明底 dataURL）
rt.getMemory(); rt.getQuality(); rt.getState(); rt.getAssetInfo(); rt.getTickInfo();
rt.destroy();
```

纯逻辑（渲染模式决策/画质档/参数钳制/换装组合/可见 drawable/face 状态机/固定步长）在 `runtime-2d5-core.js`，node 单测覆盖（`tests/runtime-2d5-core.test.mjs`）。

## 4. 参数总线（M5 互动接口）

`setParams(partial)` 接受键（越界钳制，未知键忽略）：

| 键 | 范围 | 含义 |
|---|---|---|
| `headX` / `headY` / `headZ` | ±25° | pitch / yaw / roll（M5 点头/歪头） |
| `breath` | 0–1 | 呼吸幅度（runtime 内部按时间抖动） |
| `eyeOpen` / `eyeSmile` | 0–1 | 眼态（`<0.5` 闭眼、`>0.5` 笑眼） |
| `mouthOpen` | 0–1 | 口型 0=闭 / 0.2–0.5 small/mid / ≥0.75 open |
| `hairSway` / `skirtSway` | 0–1 | 发/裙 spring 摆幅 |

另有临时通道（不占参数）：`setTalking(true)` 口型循环、`triggerBlink/Smile/Talk`、`tap()`（轻点头+笑眼+眨眼，M5 摸摸头/喂食可直接复用 `tap()` 或扩展参数曲线）。表情/口型状态机与 POC 同口径（4 眼态 × 5 口态）。

### 4.1 M5 互动接口（页面侧，不新增骨骼）

- **动作曲线**：`interaction-model.js`（纯逻辑，`tests/interaction-model.test.mjs`）把「点头/歪头/摸头反馈/喂食/打招呼」定义为参数总线上的时间函数（`headX/headZ` 等，端点回 0 无跳变）；页面用单个 rAF 驱动器写 `setParams`，同一时刻只跑一条曲线。
- **点击分区**：图框归一化坐标 `y<0.42 且 |x-0.5|<0.38` 为头部（摸摸头），其余为身体（说话）；2.5D 拖头复用现有 `setHeadFollow`。
- **宿主互动端点**（宿主为唯一经济写入；静态托管 404 → 页面 local-only 降级）：
  - `GET /feiyu/dress-up/interaction-state.json`（no-store）：`{ok, enabled, coins, mood, intimacy, today, allowed, retryIn, reasons, costs, limits}`，不含台词文本；
  - `POST /feiyu/dress-up/interaction`（JSON `{kind:'pat'|'feed'|'greet', tier?:'small'|'big'}`，需同源 + `x-feiyu-interaction: 1` + ≤2KB，令牌桶限流）：`{ok, state}` 或 409 `{ok:false, code, retryInMs}`；失败零状态变更。
- **挥手**：参数总线无手臂参数（M5 保持 59 骨同构），按 Lead 决策用「打招呼 = 点头 + 笑眼 + 气泡」替代；需要真实挥手需 M6 另立任务（会动 runtime 核心）。

## 5. 页面接线（`docs/dress-up/app.js`）

- `applyState()` 在 2.5D 模式只同步 runtime 与周边 UI（背景/特效/衣柜/立绘卡元信息），DOM 人物层不维护。
- DOM↔2.5D 共用同一 `state`（shape/outfit/top/bottom/bg/effect）；切换不重置，切回 DOM 时 `renderFigure()` 补齐图层。
- 过渡：2.5D 资产就绪后 canvas `opacity` 淡入 + `.figure.figure-dim` 淡出（背景/特效不动 → 无闪白），约 260ms。
- `say()` → runtime 口型；`pointermove` → head follow；角色点击 → `tap()`；`saveCard()` → `renderToCanvas` 合成到 900×1350 导出；`composePetImage()` → `toDataURL` 写悬浮鲸鱼小图。
- 运期失败（WebGL2 context lost / rig 加载失败）→ 自动回退 DOM 并把原因写 `render2d5Fallback`；再点按钮可重试。
- E2E/调试入口：`window.__feiyu2d5`（mode/requested/source/fallbackReason/runtime/switchTo/freeze/advance/setAuto/resources/getState/getMemory/getAssetInfo）。

## 6. 已知限制（M3 阶段，M4/M5/M6 需知）

1. **interim 资产**：M3 用户可见的 2.5D 资产来自 M2-full POC（chibi 4 组 / girl 5 组，非 production 级；chibi 无 hoodie；pose raw 口袋等 M2 已知缺陷继承）。M4 替换后同一运行时/命名约定不变。
2. **图集 vs 单独裁剪纹理**：图集把 GL 纹理从 1 个/身形（POC 37–39 个）降为 1 个、HTTP 请求 38→1，但显存从 11.67/11.02 MiB 升到 **16.34/16.62 MiB**（打包 waste + padding；仍远低于 M2 gate <40MiB）。取舍见 M3 报告。
3. **无头环境性能不可代表真机**：所有 FPS/CPU/内存为 headless SwiftShader 无 GPU 数据；真机未测，不做 60fps 承诺。
4. 2.5D 模式不显示 DIY 上传的单品（DIY 层是 DOM 675×1200 位图，M4 后续再评估）；切回 DOM 可见。
5. 背景/特效仍走 DOM/CSS（2.5D canvas 只画角色），换背景不触发 canvas 重绘。
6. **M5 互动**：心情/亲密度/鱼粮 HUD 与 2.5D 动作已接（摸头/喂食/每日问候/待机台词/换装过渡）；挥手以「打招呼」替代（59 骨同构约束）；DOM 模式无头骨，点头/歪头降级为 hop + 表情帧（文案不承诺）；`prefers-reduced-motion` 下只保留台词/HUD。
