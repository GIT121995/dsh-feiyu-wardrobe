# 身体部件掩膜（arms / hair）· v6 契约

> 归属：v0.9.0 纸娃娃分层 v6（契约见 [`docs/dress-up/LAYER-MODEL.md`](../../docs/dress-up/LAYER-MODEL.md) §3）。
> 由 mask-forge 生成并冻结；`tools/build_wardrobe.py` v6 直接读取本目录。
> 纯 CV 半自动生成（无模型/GPU），人工视觉 QA 迭代。

## 1. 文件

| 文件 | 内容 |
|---|---|
| `tools/masks/<shape>/arms.png` | 手臂 + 手（含手臂轮廓深色描边；**不含**胸/颈/脸/腿/衣物） |
| `tools/masks/<shape>/hair.png` | **前发**（含手臂下方长发丝、呆毛、耳鳍描边、发丝深色分缝；**不含**蓝鲸尾巴、不含后背中央那缕长发、不含低饱和蓝灰投影） |
| `tools/build_masks.py` | 可复现生成器（本目录 4 张掩膜全部由它重建） |

`<shape>` ∈ `chibi` / `girl`。

### 输出格式（契约）

- PNG **RGBA**：RGB 全 `255` 白，**A = 掩膜值**（当前为二值 `0/255`）。
  `build_wardrobe.load_mask()` 对 RGBA 取最后一通道，因此直接可用；
  也可 `Image.open(p).getchannel('A')`。
- 尺寸恒为 **1152×2048**（源分辨率，W×H），不缩放不插值。
- 二值硬边：下游 `body.webp/arms.webp/hair.webp` 走 premultiplied 缩放（1152→675），
  掩膜硬边在缩放时自然抗锯齿；不做额外模糊（避免糊掉手指/细发丝）。

## 2. 用法

```bash
# 重建 4 张掩膜（确定性：同一输入重跑逐像素一致）
python3 tools/build_masks.py

# 只重建一个身形
python3 tools/build_masks.py --only chibi

# 校验已落盘的掩膜是否与「当前算法重建结果」逐像素一致（CI/回归用；不一致退出码 1）
python3 tools/build_masks.py --check

# 额外输出中间调试图到指定目录
python3 tools/build_masks.py --qa-dir /tmp/mask-debug
```

- 输入素体默认为 `/home/ubuntu/dsh/.scratch/feiyu-gen/raw12/base-bandeau-{chibi,girl}.png`
  （与 `build_wardrobe.py --src` 默认值一致，可用 `--src` 覆盖）。
- 依赖：`python3` + `PIL` + `numpy` + `opencv`（无 GPU/分割模型）。

## 3. 算法

### 3.0 通用预处理

- **前景 alpha**：从四角 floodfill 去白（阈值 26），与 `build_wardrobe.remove_white_alpha`
  完全同算法。掩膜最终都与它相交（不覆盖透明背景）。
- **肤色**：`r-g>=6 & g-b>=2 & r>225 & lum>195`（暖白高亮；白色连体衣满足不了 r-g/g-b）。
- **蓝色（发/尾）**：`b-r>30 & b-g>6 & b>40`。
  `b-r` 取 30 而非常见 18：连体衣的蓝灰阴影 b-r≈19–30、亮度高，会和发丝连成一块
  （画到白毛衣上就是淡蓝污染）；收紧后发丝像素 b-r 的 2% 分位≈34、抗锯齿边≈30、
  衣物阴影 p95≈30，分离干净。

### 3.1 arms.png

1. 肤色分割后取**上身肤色连通块**：bbox-top 落在身高 27%–56% 区间、面积 ≥1.5% 画布、
   且 bbox 横跨 ≥30% 画宽的最大块。
   - 腿是独立连通块（girl bbox-top≈1145、chibi≈1369）→ 天然排除；
   - 脸/虹膜也是独立块 → 天然排除；
   - 手在腰线附近与腿纵坐标重叠，靠**连通块**而不是 y 带区分。
2. **侧向走廊**排除中央胸/颈（每身形常量，见下表），只切中央约 250–260px；
   两侧手臂（含手/手指）完全在走廊外。
3. **补描边**：`lum<110` 且距肤色核心 ≤3px 的像素（手臂深色轮廓/抗锯齿边）；
4. 再**膨胀 2px**（契约建议 1–2px），把轮廓线外侧抗锯齿纳入；
5. 与前景 alpha 相交，只保留与肤色核心连通的部分（去掉孤立描边碎点）。

### 3.2 hair.png

1. 蓝色分割（见 3.0）。
2. 逐个蓝色连通块（≥100px）排除三类「不是前发」的块：
   - **虹膜**：bbox 完全落在面部肤色块 bbox 内（面部块 = 足够大的肤色块里 bbox-top 最小者）；
   - **蓝鲸尾巴**：面积 ≥20000 **且** 质心在「身体上缘 + 55% 身高」以下；
   - **后背中央那缕长发**：质心 x 在「身体中心 ±4.5% 身宽」内 **且** bbox-top 在
     「身体上缘 + 55% 身高」以下。它在真值 look 里被裙子/围裙盖住，必须留在 body 层，
     否则会在裙面/围裙正中画出一道深色竖线（Lead 实测确认）。
3. **补深色描边**：`lum<100` 且距保留蓝色块 ≤2px 的像素，把被内部分割线切碎的发束
   连起来（发丝内部深色分缝、呆毛细线、耳鳍描边都在这一步补齐）；
4. 与前景 alpha 相交，保留 ≥200px 连通块；
5. **排除「低饱和 + 亮」像素**（`sat=(max-min)/max < 0.20 且 lum > 170`）：
   头发投在白连体衣上的蓝灰阴影 / 耳鳍浅蓝高光不是发色像素，若留在最上层 hair，
   叠到白毛衣/卫衣上会出现**淡蓝色鬼影光斑**（Lead QA 发现）；深色描边（lum 很暗）
   与蓝发主体/高光（sat 通常 >0.3）不受影响。

### 3.3 每身形标定值（源分辨率像素）

### QA 结论

1. **手完整（含手指）**：双手 3.5x tint 图逐指可见；arms 掩膜 bbox 覆盖到指尖（girl y≤1304、
   chibi y≤1502），手指间隙（线稿分隔）保留 → 叠在裙上时手指分明。
2. **胳膊完整、不含胸/颈/脸/腿**：tint 图肩以下双臂全红、颈/胸/脸/腿无红色；
   `body+plaid+arms` 合成中手出现在裙前，且胸口/领口/大腿无肤色块。
3. **hair 含下方长发丝**：`hair-compare` 2.6x 中新掩膜（品红）盖住了旧掩膜（橙）漏掉的
   手臂下方长发丝（girl x387–413/y1115–1281 等；chibi 对应侧发块），且 `plaid-hair`
   合成中该长发丝盖在裙面上可见（旧掩膜下会被裙吞掉）。
4. **hair 不含尾巴 / 后背中央缕**：tint 中尾巴保持原蓝色、无绿；`plaid-hair` 裙正中
   为纯裙面，无深色竖线（后背中央缕已排除、留在 body 被裙盖住）。
5. **无淡蓝鬼影**：`sweater-chest-4x` 中「hair ON」与「hair OFF」对照，白毛衣上无低饱和
   蓝灰光斑（低饱和+亮像素已从 hair 掩膜剔除）。
6. arms 掩膜只覆盖手臂+手；`sweater-insitu` 最终 drawOrder 下袖口/毛衣无缝、无皮肤色块
   盖在衣服上（长袖由 `sleeve` 盖回，mask 与 sleeve 同源）。

## 6. 复现性与确定性

- 算法无随机数；同一输入、同一 opencv/numpy 版本重跑逐像素一致（已用 md5 双跑校验）。
- `python3 tools/build_masks.py --check` 对已落盘文件做逐像素回归比对（不一致退出码 1）。

## 7. 已知误差 / 风险（偏保守可接受）

- **边界 1–2px 误差**：掩膜由 CV + 人工 QA 生成；描边补全 + 2px 膨胀会把手臂轮廓
  纳入，比真实皮肤轮廓外扩约 1–2px。契约里 `sleeve` 再膨胀 6px 兜底，因此不会露缝。
- **肩部内侧/腋下被走廊裁掉一小条手臂皮肤**：这些像素在任何有袖子上衣下都被
  `topBody`/`sleeve` 覆盖，视觉无影响；无袖/抹胸款时该区域无衣物，body 层像素相同。
- **肩侧发丝在真值 look 里可能位于衣服后**：v6 契约「hair 最上层，永远在衣服前」是
  近似（见 LAYER-MODEL §6）；本掩膜按契约把可见前发全部置顶，因此长袖毛衣上肩侧
  发缕会覆盖衣服（与真值 look 存在细微差异）。如后续要精确，可拆 `hairBack` 槽位。
- **耳鳍内部浅蓝高光**：大部分按「低饱和+亮」规则排除，仅保留耳鳍深色描边；耳鳍
  区域永远不被衣物覆盖，少画的部分由 body 层原像素补足，无视觉差异。
- **尾巴描边**：尾巴整体被排除；hair 边缘与尾巴相邻处可能有 ≤2px 的深色描边残留，
  位于发尾/尾根交界的轮廓线上，属发丝自身描边，视觉无异常（QA 图已确认）。
- 输入必须是**白底** 1152×2048 素体（`base-bandeau-<shape>.png`）；换素体需重新标定
  §3.3 常量并重跑本 QA 流程。
